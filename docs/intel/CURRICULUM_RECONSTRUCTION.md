## 2. Conceptual progression and dependencies

Within Module 1, the sequence is genuinely cumulative and load-bearing: L1 establishes that caps differ by structural type (soft/hard/none), L2 layers a marginal-cost mechanism onto the NBA's soft cap, and L3 explicitly says it is skipping a new activity *because* it depends on the roster-building and spending decisions the student already made in L1/L2 (p. 189) — this is the single clearest example in the document of an intentional, stated inter-lesson dependency.

Module 2→3 continuity is asserted rhetorically ("we've been following how money flows," p. 196) but not mechanically — no lesson requires an artifact (roster, budget, or score) carried over from a prior lesson the way Module 1 does. Module 3's three lessons build a clean concept ladder (find value → reconcile value with qualitative judgment → generalize into four measurement pillars), each explicitly referencing the lesson before it (p. 211, p. 216). Module 4 is the most self-contained arc in the document: L1 (draft = probability, not ranking) is a prerequisite the L2 script literally invokes by name ("Last time, we talked about…", p. 237), and L2's floor/ceiling vocabulary is a stated prerequisite for L3's fit-vs-BPA framework (p. 241). So dependency chains exist *within* modules 1, 3, and 4, but there is no evidence of a chain that spans modules — nothing a student built in Module 1 (a roster, a cap sheet) is reused as an input in Module 2, 3, or 4's activities. Given the founder's stated preference that "module continuity is desirable when prior decisions create meaningful future consequences," this is a real gap: the raw material (a persistent GM roster/cap sheet) exists in Module 1 and is simply dropped afterward.

## 3. Misconceptions the curriculum targets

Explicitly and effectively targeted: (a) "the draft is a ranking" → reframed as expected value over a probability distribution (p. 226–228); (b) "clutch performance = statistical reliability" → shown to diverge from base rates using Kobe/LeBron/Ortiz data (p. 5); (c) "the luxury tax is a spending ban" → reframed as a marginal, bracketed price (p. 117, 350); (d) "best player available and fit-based drafting are opposing philosophies" → reframed as compatible under a timeline constraint (p. 232–235); (e) "stats and scouting are rivals" → reframed as complementary evidence sources (p. 211–214); (f) "small-market teams can't compete" → reframed via revenue-sharing mechanics (p. 196–197); (g) "spending money buys wins" (implicitly, via the Mets/Warriors contrast run twice, p. 118–120, 191–192).

Misconceptions the curriculum leaves untouched at the 101 level: risk vs. *uncertainty* as distinct concepts is taught explicitly only at Track 301 (p. 22–23, "Risk vs Uncertainty… information asymmetry") — Track 101 uses "floor/ceiling/volatility" language (Module 4) that brushes against this distinction without ever naming it, so a 5th/6th grader is not given the risk-vs-uncertainty vocabulary the curriculum's own later tracks treat as important. Opportunity cost is named as a target concept for Module 3 in the founder's own TODO notes (p. 287: "opportunity cost, marginal returns, expected value, scarcity, incentives, game theory, compounding") but is not explicitly surfaced as a labeled concept in any produced Track 101 script — it is present implicitly (e.g., trading flexibility for star power in the Apron lesson) but never named as a concept a student should walk away able to define. Bargaining/negotiation — a labor-market concept central to real front-office economics and explicitly planned as Module 4's theme in the original mastersheet (p. 13, "Negotiation Basics") — is entirely absent from the produced Track 101 curriculum; the module was redirected to draft strategy instead (see §6).

## 4. Constraints: timing, format, teacher role

**Timing.** Episodes are described as "usually around five minutes" (Mission 0 script, p. 261); Module 3/4 scripts carry internal timestamps totaling roughly 6–8 minutes per lesson (e.g., p. 208 "0:00–6:30", p. 237 "6–8 minutes"). No total weekly or per-session classroom time is specified anywhere for Track 101; "Expected weekly time" is listed as a still-to-be-written field on the (Track 201) Teacher/Admin page (p. 289).

**Classroom format.** The described delivery model is self-paced and asynchronous, not a live-taught lesson: students listen to a podcast episode, complete an activity (commonly a Google Form/Slides/Sheet), and submit a "claim code" for XP (p. 261, p. 279–285). Google Classroom is the intended grading backend, with teachers entering claim codes as "private comments" (p. 279, 284–285). There is no scripted teacher-facilitation moment, discussion protocol, or whole-class debrief anywhere in the Track 101 material — the founder's own TODO list confirms this is deliberate for now: "What teachers need (nothing — it's all done for them)" (p. 289).

**Teacher role.** Effectively passive/administrative: distribute the Form/Classroom link, grade the submitted artifact against an unwritten rubric, and hand-enter claim codes. A "Teacher/School Admin Page" with learning objectives, standards alignment, and a facilitation guide is listed as not-yet-built (p. 289), and a "Teacher Guide PDF" is marked optional/Phase 3 (p. 290). This matters directly for the "class evidence worth discussing" product bar: as currently scripted, there is no designed mechanism for turning individual student choices into a shared classroom conversation — outcomes are consumed solo (podcast → form → private code), not compared or debated as a group.

## 6. Internal contradictions and gaps (ranked by consequence)

1. **Module 4's theme changed completely between planning and production**, with no reconciliation note anywhere in the file. Planning mastersheet: "Module 4 — Negotiation Basics" — contracts, agents, rookie extensions, negotiation simulation (p. 13). Produced scripts: three full episodes on **the draft** (ranking myth, floor/ceiling, BPA-vs-fit) with zero mention of negotiation (p. 226–241). A downstream builder reading only the mastersheet would build the wrong module.
2. **Three non-identical Module 2/3 outlines coexist** (p. 12 vs. p. 245/250 vs. p. 252), disagreeing on lesson titles, activities, and — critically — **claim codes for the same lesson** (e.g., Module 2 Lesson 1 has at least three different titles and two different claim codes: `L1-101-M2-REVENUE` and `L1-101-M2-MONEY`, pp. 245, 247). If claim codes drive XP/gradebook logic downstream, this is a live data-integrity risk, not just a documentation nit.
3. **The planned Module 1 Lesson 4 ("Rookie Contracts & Bird Rights") and Module 3 Lesson 4 / Module 2 Lesson 4 "case study" lessons were never produced** — every module that shipped content converged on 3 lessons, not the 4 originally planned (p. 12 vs. actual scripts). This is worth surfacing to the founder as *positive* evidence that 3-lesson modules, not 4, are what the team naturally converges on in practice — consistent with the current "~3 lessons" framing.
4. **No Track 101 capstone or cross-module synthesis exists**, unlike Track 201 (pp. 294–301) and Track 301 (p. 26). For an audience the founder specifies as grades 5–6, the absence of *any* culminating "defend your reasoning" moment is a gap relative to the product bar's DEFEND verb.
5. **The productization roadmap targets Track 201 ("middle school, grades 7–9"), not Track 101.** The entire "what's left to build before schools" plan (pp. 286–293) — homepage, onboarding page, teacher/admin page, learning objectives, standards alignment — is scoped to Track 201. If the refounded product's audience is genuinely grades 5–6, none of that planning work transfers directly, and it is unclear from this document whether anyone intended Track 101 to reach schools on its own.
6. **The gamification layer ("BOW ID": XP, levels, "cosmetic scarcity," status strings like `BOW|201|F25|L7|XP1850|M6|ACTIVE`, "Fortnite-energy," p. 306–315) is in direct tension with the current mandate against "leaderboard theater."** This is the most fully-developed system in the entire back half of the document — more developed than any Track 101 lesson's assessment design — and it is built around collectible credentials and cosmetic status, not around comparing decisions or debating outcomes.
7. **No explicit learning objectives, standards alignment, or economics-concept labels exist per lesson.** The founder's own TODO list (p. 287) confirms these are unwritten. Economic concepts had to be inferred by the reconstruction above from script content, not read off a stated objective.
8. **Lesson timing/format is internally inconsistent**: some lessons carry minute-by-minute timestamps (Module 3/4), others don't (Module 1/2); no lesson states a target classroom-minutes budget consistent with any particular class period length.

## 7. Cross-track context (for comparison only — Track 101 is the founder-fixed scope)

Track 201 and 301 apply the same "podcast → activity → claim code" pattern to older audiences, but with materially more sophisticated design in places: Track 301's "MODULE 2 SYNTHESIS (PURE ECONOMICS)" sections (pp. 18–26) strip sports language entirely and test the underlying economic reasoning directly via MCQs on expected value, elasticity, opportunity cost, and path dependence — a "sports scaffold, then pure-econ check" pattern that does not appear anywhere in Track 101. Track 201's capstone rubric (pp. 294–301) — problem definition → stakeholder incentives → proposed solution → tradeoffs → risk stress-test → recommendation memo — is a well-built model of the DEFEND/REVISE product bar the founder wants, but it exists only for older students right now.
