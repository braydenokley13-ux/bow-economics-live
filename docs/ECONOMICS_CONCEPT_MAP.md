# Economics Concept Map

Concept → student action → experienced moment → class evidence → formalization line → beyond-
sports generalization, for every synthesis concept in the two built experiences. Wording is
pulled from the source specs/verify docs, not paraphrased where a direct quote exists.

**Audit status differs by module:** M1 L1's cards are **verifier-audited** — each has an
independent per-concept verdict from `VERIFY_ECONOMICS.md` and a round-2 re-check from
`VERIFY_ROUND2.md`. M2's four concepts are **spec-level only** (`PROTOTYPE_SPEC.md`) — no
VERIFY_GAMEPLAY/ECONOMICS/RUNTIME pass has been commissioned for Module 2 yet (see
`docs/RAMAZ_READINESS.md`).
